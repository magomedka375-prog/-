# -# 🗺 Карта пространства

Интерактивный сервис для навигации внутри зданий и мероприятий: 2D-план, панорамы 360°, маршруты, статистика.

## ✨ Возможности

- 🏢 **Кампус → Здание → Этаж** — поддержка нескольких зданий и этажей
- 🗺 **2D-план** с точками (стенды, входы, Wi-Fi, услуги)
- 🌐 **Панорамы 360°** с хотспотами для перехода между помещениями
- 🧭 **Навигация** — построение маршрута алгоритмом A* по графу точек
- 📊 **Статистика** — просмотры карт, точек и панорам (для организаторов)
- 📴 **Офлайн** — Service Worker кэширует панорамы и страницы
- 🔐 **Авторизация** — JWT для организаторов
